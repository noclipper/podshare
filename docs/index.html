How it works

Two commands. No accounts.

  • You send. In the folder you used the agent in, run podshare send and pick the chat. Or ask for it inside Claude Code (/podshare:share) or Codex, with the plugin.
  • Only what the chat used. podshare sends the files the chat read or changed, plus setup files like package.json and the skills it used. Not your whole project. You see the list and can untick anything.
  • They receive. They run podshare receive with your code anywhere, see what's coming and its token cost, and accept. It unpacks into a new folder there, and their agent opens with your chat.
  • It's safe to open. The agent starts in plan or read-only mode, so it can read the files but changes nothing until they approve.

Privacy

Secrets are filtered before anything leaves.

You see everything before it's sent, and can untick any file. Commands and tool results podshare can't check are left out.

  • Keys and passwords it recognises are removed, and so are the agent's repeats of them.
  • Secret files like .env, keys and personal folders are never sent.
  • Your identity (name, email, computer, account IDs) is replaced in the chat.
  • Agent settings (hooks, MCP servers, permissions) never travel.

Install

One line.

Open a terminal (Terminal on Mac, PowerShell on Windows) and run the line for your computer. The person you send to needs it too.

Mac 
brew install noclipper/tap/podshare
Linux 
curl -LsSf https://github.com/noclipper/podshare/releases/latest/download/podshare-installer.sh | sh
Windows 
powershell -ExecutionPolicy Bypass -c "irm https://github.com/noclipper/podshare/releases/latest/download/podshare-installer.ps1 | iex"
Node.js 
npm install -g podshare

Rather stay inside your agent? Add the plugin too (podshare still needs to be installed above). For Claude Code, type these into its chat box, then use /podshare:share. For Codex, run these in a terminal, then ask Codex to "share this chat with podshare".

Claude Code 
/plugin marketplace add noclipper/podshare
/plugin install podshare@podshare
Codex 
codex plugin marketplace add noclipper/podshare
codex plugin add podshare@podshare

Questions

Good to know.

Does my code go to a server?

Not in any form anyone can read. It's encrypted end to end and goes directly when it can, otherwise through a public relay that can't read it.

Is my whole project sent?

No. Only the files the session used, plus setup files like package.json.

Do skills come along?

Yes. The project's skills always do. Skills from your own setup or a plugin go only if you say yes. They land where the other person's agent looks, Claude Code or Codex.

Do we both need to be online?

To send by code, yes. Otherwise podshare pack makes a file you can send later.

Any size limits?

Files over 10 MB are left out unless you say so; podshare asks. A pod can be up to 2 GB.

What's next?

Gemini CLI, send-later links that work when they're offline, and big files sent as a link to your git repo.

Can I read the code?

Yes, it's on GitHub.
